#  House Rent Management System with AI Recommendation

## Overview

The House Rent Management System is a web-based platform that helps tenants find rental properties and allows property owners to manage listings efficiently. The system uses Artificial Intelligence to recommend suitable properties and provide vacancy notifications.

## Features

* User Registration and Login
* Property Listing Management
* Property Search and Filtering
* AI-Based Property Recommendations
* Vacancy Notifications
* Rent Price Prediction
* Location-Based Search
* Favorite Properties
* Booking Management

## Technology Stack

* MongoDB
* Express.js
* React.js
* Node.js
* Python
* FastAPI
* Machine Learning

## Project Objective

To simplify the house renting process by providing a centralized platform with intelligent recommendations, real-time vacancy updates, and transparent property information.
